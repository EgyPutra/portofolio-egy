# Keputusan desain

Website personal dan editorial untuk pengunjung dari Instagram/WhatsApp. Arah visual mengikuti ekspor Stitch: hangat, dewasa, burgundy, foto natural, dan ritme ruang yang lega.

Dial desain: variance 6, motion 3, density 3. Gerakan dibatasi pada umpan balik hover dan tombol agar pembacaan tetap tenang. Reduced motion menghilangkan animasi. Tema terang dipertahankan sesuai PRD dan referensi; tema terkurasi Rose hanya mengubah tint, bukan membalik warna antarbagian.

Palet: #FAFAFA, #FFFFFF, #27272A, #52525B, #E4E4E7, #7D3448, #F5EDF0. Fraunces dipakai karena diminta PRD; Geist untuk isi dan dashboard. Keduanya self-hosted. Serif pada dashboard hanya terdapat di iframe pratinjau website.

Radius: kontrol 10px, foto/modul 14–18px, badge status full. Konten 1200px maksimum; 48px margin desktop dan 20px mobile. Z-index: navigasi 20, skip link 40, pratinjau Studio 100; dialog native berada pada top layer.

Penyempurnaan referensi: menu keyboard/mobile, pencarian & kategori yang dikombinasikan, area sentuh 44px, teks kontras, section perjalanan tanpa kartu identik, caption di luar foto, label foto ilustrasi, gambar gagal, keadaan kosong, dan dialog tautan belum diatur.

Tidak ada statistik, testimoni, penghargaan, atau angka penghasilan rekaan. Foto ilustrasi dari desain diberi label; dokumentasi arsip lama ada pada docs/source-archive agar tidak ikut disalin ke hosting publik.
